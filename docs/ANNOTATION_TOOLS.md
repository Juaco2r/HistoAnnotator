# Annotation tools

## Move

Pan and zoom through the image. On tablet devices, touch gestures can be
used for navigation.

## Freehand

Draw a freehand contour.

## Brush

Paint annotation regions using an adjustable brush diameter. When drawing
over a selected annotation of the same class, Brush can add geometry to
that annotation.

## Polygon

Create a polygon by defining vertices and finishing the contour.

## Rectangle

Create rectangular annotations.

## Circle

Create circular or elliptical annotations. Construction settings can
control how the shape is defined and scaled.

## Wand

Select a locally similar image region using visible color or brightness.

## Selection

Annotations can be selected individually or in groups. Available geometry
operations include delete, merge, intersect and subtract.

## Modifier keys

Desktop keyboard workflows include modifier-assisted operations such as
Shift for additive behavior and multi-selection where applicable.

## Classes

Annotations have a classification name and display color. GeoJSON export
preserves QuPath-oriented annotation classification information.

## GeoJSON

HistoAnnotator supports import, export and Android sharing. Coordinates are
stored in image level-0 pixels.
