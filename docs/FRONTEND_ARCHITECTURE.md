# Frontend architecture after initial modular refactor

The frontend now has two layers:

- **Maintained modular source**: `app/static/frontend/*.part.js`
- **Generated runtime bundle**: `app/static/app.js`

The runtime bundle remains a single IIFE for compatibility with:

- the existing browser deployment;
- Capacitor/Android asset copying and native-server injection;
- OpenSeadragon and offline/local-image integration;
- existing shared annotation/viewer state;
- the characterization harness.

The source boundaries correspond to dependency clusters identified during the
architectural audit rather than equal-sized chunks. This removes the requirement
to work inside a single 35k-line source file while preserving observable behavior.

`app.js` is regenerated by `scripts/build_frontend_bundle.py`. CI/local
characterization and Android asset preparation reject a stale bundle.

A future migration to native ES modules should be incremental and should first
extract explicit state/service interfaces from these source domains. It is not
required for the initial modular refactor to be considered complete.
