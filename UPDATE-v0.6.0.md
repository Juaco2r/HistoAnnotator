# HistoAnnotator v0.6.0

- Drawing workflow selector: Default / Pathologist.
- Pathologist Freehand persists across pen lifts; Complete annotation button closes it.
- Inner contour subtraction creates holes and supports contours touching the outer boundary through boolean difference.
- Pathologist Brush automatically adds subsequent strokes to the current annotation.
- Independent annotation files per image.
- Long-press browser context menu suppressed inside the viewer.
