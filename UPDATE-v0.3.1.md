# HistoAnnotator v0.3.1

- Fingers always pan and pinch-zoom, even while an annotation tool is active.
- Pen creates or edits annotations according to the selected tool.
- Desktop left mouse remains an annotation fallback; select **Mover** to navigate with the mouse.
- Short palm-rejection window suppresses accidental touch input while the pen is down.
- Visible input guide and diagnostics describe the active behavior.
