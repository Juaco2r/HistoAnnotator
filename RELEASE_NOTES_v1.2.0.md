# HistoAnnotator v1.2.0

HistoAnnotator v1.2.0 expands the project from Web + Android into a
cross-platform annotation environment.

## Highlights

- Windows, Linux and macOS Desktop applications.
- Android local-image mode.
- Android runtime server switching.
- QR pairing between Desktop and Android.
- Native Android network transport for server images and tiles.
- Large TIFF preparation bundled into Desktop with pyvips/libvips.
- QuPath-compatible GeoJSON annotation workflows.
- Review mode, annotation statistics and calibration support.

## Assets

- Windows x64 portable ZIP
- Linux x64 portable tar.gz
- macOS Apple Silicon portable tar.gz
- macOS Intel portable tar.gz
- Android APK
- SHA256 checksums

## Research software

This release is intended for research and testing. It is not clinically
validated medical software and does not currently provide individual user
authentication, a complete audit trail or regulatory controls.

The generic public Android APK does not contain deployment-specific private
certificate authorities or private server addresses.
